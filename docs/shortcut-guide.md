# iOS 快捷指令接入指南

快捷指令（Shortcuts）可以**程序化遍历照片/相册**并逐个调用服务端——这是网页端做不到的（网页拿不到相册名、没有全选）。配合服务端的内容去重：重复运行快捷指令会自动跳过已传项，中断了重跑即可，安全无害。

> 大视频建议仍用网页上传（网页有分块断点续传；快捷指令一次发整文件，大文件失败要整文件重来）。
> 照片（几 MB 级）用快捷指令最合适。

## 准备

1. 电脑上 `npm start`，放行防火墙（README）。
2. 记下带密钥的地址，例如：`http://172.22.1.188:5284/k/P2QDMD2TSDCY`（手机能打开的那个）。
3. **必做**：iPhone 上打开 iOS 的"允许共享大量照片"开关——不开的话，循环传照片传到第几张就会被 iOS 拦停，报"此操作正尝试共享 N 个照片项目"。
   - iOS 18+：设置 → App → 快捷指令 → 高级 → 打开「允许共享大量照片」
   - iOS 17：设置 → 快捷指令 → 高级 → 同上

## 搭建「按相册同步」快捷指令（约 10 分钟）

每个相册复制一份、只改两处参数（相册过滤器 + URL 里写死的相册名）。

动作清单（自上而下，在快捷指令 App 里逐个添加；2026-11 实测通过的极简版）：

1. **查找照片**（Find Photos）：
   - 添加过滤器 → `相册` → `是` → 选 `家人`
   - **再加一个过滤器 → `媒体类型` → `是` → `图像`**（实测：循环撞上视频会长时间卡在"导出"上，看起来像卡死；视频走网页传，快捷指令只管照片）
   - 关闭"限制数量"（取回全部）；调试期可加"拍摄日期介于…"缩小范围
2. **对每个项目重复**（Repeat with Each）：重复对象选 `照片`
3. 循环体内依次：
   - **获取详细信息**（Get Details）→ 类型 `照片` → `名称`（得到文件名变量）
   - **获取 URL 内容**（Get Contents of URL）：
     - 方法：`POST`
     - URL 栏一栏填完，**只有一个蓝色变量**（名称）：

       `http://172.22.1.188:5284/k/P2QDMD2TSDCY/api/quick?name=`**[名称]**`&album=家人`

     - 相册名**直接打字写死**（如 `家人`），不引用变量——每个相册复制一条指令改这里
     - `&` 字符别丢：删变量时 iOS 容易把相邻字符一起选中删掉，删完检查一遍
     - 请求体：`表单` → 添加新字段 → 名称 `file` → 类型 `文件` → 值 `重复项目`
4. 命名为「同步-家人」，保存。

> **不需要 mtime/日期格式化动作**：服务端自动从照片 EXIF / 视频元数据读拍摄日期归档到 `YYYY-MM/`（实测准确），快捷指令里拼日期又长又易错，删掉。
> 请求体选 `表单` 而不是 `文件`：`文件` 通道走系统共享导出，会触发 iOS 共享数量闸。
> 排错利器：服务端 `data/logs/server-*.log` 会记录每条到达的原始查询串（搜"quick 请求"），URL 拼错一眼定位，不用截图猜。

> 别名提示：不同 iOS 版本动作名略有差异（"获取 URL 内容"/"从 URL 获取内容"、"对每个项目重复"/"重复每个项目"），按语义找即可。
> 快捷指令首次运行会请求照片权限，选"所有照片"。

## 「全量」怎么跑

- 快捷指令**严格串行**（约 1–2 秒/张），10 万张全库一次跑完要 30–50 小时——可以**分时段挂机跑**：给"查找照片"加过滤器 `拍摄日期` 在某个区间（如一年），每年/每月跑一轮；中断了直接重跑同一区间（已传项服务端秒级跳过，只有查重请求开销）。
- 跑的期间：**设置 → 显示与亮度 → 自动锁定 → 永不**，并停留在快捷指令 App 前台——锁屏/切后台会挂起执行，看起来像卡住（进度突然停滞多半是这个或撞上视频）。
- 中断恢复：直接重新运行同一快捷指令即可，无需任何清理。
- 跑完后在网页"浏览"页核对：相册数/张数/月份分布。

## 大视频怎么办

- 网页端（Safari 打开同步页）：相册名填好 → 拖选视频 → 分块上传 + 断点续传。
- 快捷指令不建议传大视频：单请求整文件发送，手机内存与超时都容易失败。

## 故障排查

| 现象 | 处理 |
|---|---|
| 报"此操作正尝试共享 N 个照片项目，这不受允许" | iOS 共享保护闸：设置 → App → 快捷指令 → 高级 → 打开「允许共享大量照片」 |
| 照片全归到"未整理"目录 | URL 里 `album` 段拼错（多了/少了变量或 `&`）；看服务端日志"quick 请求"的原始查询串一眼定位 |
| 手机打不开网页/快捷指令报"无法连接服务器" | 检查防火墙规则（管理员运行 scripts/firewall.ps1）；确认电脑与手机同一 Wi-Fi 且 Wi-Fi 为"专用网络" |
| 快捷指令运行但服务端无文件 | 看服务端日志"quick 请求"确认请求到达与参数；`BAD_KEY`=密钥错；`INSUFFICIENT_SPACE`=磁盘满 |
| 提示 `NOT_LAN` | 服务端只接受私网地址；手机走蜂窝网络就会报这个 |
| 重复运行没有跳过旧文件 | 确认 URL 的 name 是干净的 `名称` 变量且 `&album=` 正常（服务端按 文件名+大小 指纹秒跳） |
